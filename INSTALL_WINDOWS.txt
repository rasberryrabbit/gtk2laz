gtk2laz v1.7 - Windows 설치 방법
================================

방법 1: Python 소스 직접 실행 (권장)
----------------------------------
1. Python 3.8+ 설치 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크 필수
2. pip install pycparser pcpp
3. 실행:
   windows\gtk2laz_win.bat gui
   windows\gtk2laz_win.bat convert E:\path\to\source E:\path\to\output


v1.7 변경 사항
=============
* 패턴 변환기에도 linkage-marker 제거 적용
  - AST 경로 + 패턴 경로 모두 _strip_unknown_linkage_markers() 호출
  - G_MODULE_EXPORT, GDK_AVAILABLE_IN_ALL, _GLIB_EXTERN, SDL_FORCE_INLINE 등
    알 수 없는 linkage marker를 패턴 경로에서도 자동 제거

* _FUNC_DEF_RE 정규식 일반화
  - 기존: G_MODULE_EXPORT만 개별 처리
  - 이제: 임의의 ALL_UPPERCASE 식별자를 linkage marker로 허용

* v1.6의 모든 기능 유지:
  - 일반화된 linkage-marker 제거 (pcpp 후처리 단계)
  - String-aware comment stripping
  - C 바이트 배열 → Pascal 배열 상수 변환
  - typedef chain flattening
  - GResource, GStaticResource fake 타입 정의
