gtk2laz v1.8 - Windows 설치 방법
================================

방법 1: Python 소스 직접 실행 (권장)
----------------------------------
1. Python 3.8+ 설치 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크 필수
2. pip install pycparser pcpp
3. 실행:
   windows\gtk2laz_win.bat gui
   windows\gtk2laz_win.bat convert E:\path\to\source E:\path\to\output


v1.8 변경 사항
=============
* Usage-based identifier classifier 도입 (사용자 제안)
  - marker 후보를 strip하기 전에 전체 텍스트를 한 번 스캔해서
    각 대문자 식별자를 type / const / variable / unknown로 분류
  - 분류 기준:
    * typedef ... NAME; → type (가중치 3)
    * NAME *foo → type (가중치 2)
    * NAME x; (x는 소문자) → type (가중치 1)
    * (NAME)expr → type (캐스트, 가중치 2)
    * sizeof(NAME) → type (가중치 3)
    * = NAME; → const (상수)
    * NAME(...) → variable (함수 호출)
    * NAME = ...; → variable (할당)
  - 분류가 'type'이면 marker로 strip하지 않음 (GtkWidget *window; 보호)
  - 분류가 'const'/'variable'/'unknown'이면 marker로 간주하고 strip
  - 보수적 결정: 의심스러우면 'type'으로 분류 (잘못 strip하면
    AST 파싱이 깨지는 것보다 marker를 남겨서 명확한 에러 메시지가
    나오는 편이 더 안전)

* _strip_linkage_marker_same_line에도 usage_map 전달
  - 같은 줄에 있는 marker도 usage_map 확인 후 strip 결정
  - Case B (NAME *foo): next_ident도 usage_map에서 type인지 확인

* v1.7의 모든 기능 유지:
  - 패턴 경로 일관성 확보
  - 일반화된 linkage-marker 제거
  - String-aware comment stripping
  - C 바이트 배열 → Pascal 배열 상수 변환
  - typedef chain flattening
  - GResource, GStaticResource fake 타입 정의
