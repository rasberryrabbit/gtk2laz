gtk2laz v2.0 - Windows 설치 방법
================================

방법 1: Python 소스 직접 실행 (권장)
----------------------------------
1. Python 3.8+ 설치 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크 필수
2. pip install pycparser pcpp
3. 실행:
   windows\gtk2laz_win.bat gui
   windows\gtk2laz_win.bat convert E:\path\to\source E:\path\to\output


⚠️ 중요: 한 번에 한 플랫폼만 변환 가능
-------------------------------------
C 전처리기는 `--platform` 플래그(windows / linux / macos / auto)로
한 플랫폼의 #ifdef 분기만 선택합니다. 다중 플랫폼 소스(예: Windows의
SetupDi* + Linux의 /dev/hidraw*)를 변환할 때는 플랫폼별로 한 번씩
gtk2laz를 실행한 후, 결과 .pas 파일들을 FreePascal의
{$IFDEF MSWINDOWS} / {$IFDEF UNIX} 블록으로 직접 병합해야 합니다.


v2.0 변경 사항
=============
* C 언어 키워드와 C 표준 라이브러리 타입 별칭 분리 (사용자 제안)
  - 기존: size_t, ssize_t, ptrdiff_t, wchar_t를 _C_TYPE_KEYWORDS로
    잘못 분류 (C 언어 키워드가 아님!)
  - 이제: _C_TYPE_KEYWORDS는 진짜 언어 키워드만 (int, void, struct...)
  - 새 _C_LIBC_TYPE_ALIASES 세트로 라이브러리 타입 별칭 분리:
    * <stddef.h>: size_t, ptrdiff_t, wchar_t, max_align_t
    * <stdint.h>: int8_t, int16_t, int32_t, int64_t, uint8_t, ...
    * <stdio.h>: FILE, fpos_t
    * <time.h>: time_t, clock_t
    * <wchar.h>: wint_t, mbstate_t
    * <setjmp.h>: jmp_buf, sigjmp_buf
    * <signal.h>: sig_atomic_t
    * POSIX <sys/types.h>: ssize_t, pid_t, uid_t, gid_t, off_t, mode_t, ...
  - _C_ALL_KNOWN_TYPES로 결합하여 marker stripper와 classifier 모두 사용
  - size_t를 C 키워드로 잘못 분류하던 개념적 오류 수정

* v1.9의 모든 기능 유지:
  - Usage-based identifier classifier (대소문자 구분 없이)
  - 소문자 linkage marker 제거 허용
  - 패턴 경로 일관성 확보
  - 일반화된 linkage-marker 제거
  - String-aware comment stripping
  - C 바이트 배열 → Pascal 배열 상수 변환
  - typedef chain flattening
  - GResource, GStaticResource fake 타입 정의
