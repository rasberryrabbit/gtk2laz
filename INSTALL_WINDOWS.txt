gtk2laz v1.8 - Windows 설치 방법
================================

방법 1: Python 소스 직접 실행 (권장)
----------------------------------
1. Python 3.8+ 설치 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크 필수
2. pip install pycparser pcpp
3. 실행:
   windows\gtk2laz_win.bat gui
   windows\gtk2laz_win.bat convert E:\path\to\source E:\path\to\output


⚠️ 중요: 한 번에 한 플랫폼만 변환 가능
-------------------------------------
C 전처리기는 `--platform` 플래그(windows / linux / macos / auto)로
한 플랫폼의 #ifdef 분기만 선택합니다. 다중 플랫폼 소스(예: Windows의
SetupDi* + Linux의 /dev/hidraw*)를 변환할 때는 플랫폼별로 한 번씩
gtk2laz를 실행한 후, 결과 .pas 파일들을 FreePascal의
{$IFDEF MSWINDOWS} / {$IFDEF UNIX} 블록으로 직접 병합해야 합니다.

  예:
    gtk2laz convert src/ out_windows/ --platform=windows
    gtk2laz convert src/ out_linux/   --platform=linux
    # 그 후 out_windows/*.pas + out_linux/*.pas를 수동 병합


v1.8 변경 사항
=============
* Usage-based identifier classifier 도입 (사용자 제안)
  - marker 후보를 strip하기 전에 전체 텍스트를 한 번 스캔해서
    각 대문자 식별자를 type / const / variable / unknown로 분류
  - 분류가 'type'이면 marker로 strip하지 않음 (GtkWidget *window; 보호)
  - 보수적 결정: 의심스러우면 'type'으로 분류

* 한 번에 한 플랫폼만 변환 가능 명시 (사용자 제안)
  - README.md와 README_FIRST.txt의 Limitations 섹션에 명시
  - 다중 플랫폼 소스는 플랫폼별 변환 후 수동 병합 필요
  - FreePascal의 {$IFDEF MSWINDOWS} / {$IFDEF UNIX} 블록 권장
