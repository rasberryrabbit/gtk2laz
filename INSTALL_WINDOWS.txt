gtk2laz v2.2 - Windows 설치 방법
================================

방법 1: Python 소스 직접 실행 (권장)
----------------------------------
1. Python 3.8+ 설치 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크 필수
2. pip install pycparser pcpp
3. 실행:
   windows\gtk2laz_win.bat gui
   windows\gtk2laz_win.bat convert E:\path\to\source E:\path\to\output


⚠️ 중요: 한 번에 한 플랫폼만 변환 가능
-------------------------------------
C 전처리기는 `--platform` 플래그(windows / linux / macos / auto)로
한 플랫폼의 #ifdef 분기만 선택합니다. 다중 플랫폼 소스(예: Windows의
SetupDi* + Linux의 /dev/hidraw*)를 변환할 때는 플랫폼별로 한 번씩
gtk2laz를 실행한 후, 결과 .pas 파일들을 FreePascal의
{$IFDEF MSWINDOWS} / {$IFDEF UNIX} 블록으로 직접 병합해야 합니다.


v2.2 변경 사항
=============
* 패턴 변환기(Path fallback)에도 byte-array 초기화 처리 추가
  - AST 경로가 실패할 때만 작동하는 fallback path
  - AST 경로: 정확한 record type + byte array + record initializer 생성
  - 패턴 경로: 단순한 byte array initializer 생성 (부분 지원)
  - 패턴 경로는 pcpp를 거치지 않으므로 #ifdef 분기 처리가 안되어
    제한적 (AST 경로 권장)

* 패턴 경로 개선:
  - __attribute__((...)) GCC annotation 제거 (balanced-paren scan)
  - static/extern/const/volatile storage class 키워드 strip
  - C byte-array initializer (문자열 리터럴 나열) → Pascal byte array
  - init_text recovery (원본 소스에서 { ... } 복구)
  - _pattern_byte_array_init_to_pascal 헬퍼 추가

* v2.1의 모든 기능 유지:
  - resources.c의 gresource 패턴 처리 (익명 union + byte-array)
  - struct InitList → Pascal record constant 변환
  - typedef → struct 정의 resolve
  - sizeof/UnaryOp, StructRef, BinaryOp, Cast 등 초기화 표현식 처리
